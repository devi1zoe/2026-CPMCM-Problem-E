# 注意力实验运行说明

所有本轮文件位于 `step2_attention`。数学公式见[模型定义](模型定义.md)，实测结论见[注意力实验报告](注意力实验报告.md)。

## 环境与数据

复用 `/usr/local/python3.10/bin/python3`、PyTorch 2.5.1+cu121，以及已有 `step1/.venv` 中的transformers等依赖。已阅读 `~/.bashrc_hyf`，未修改根Python环境、未安装依赖、未新建环境。GPU1/2/3分别训练种子17/29/43，GPU0不参与本轮。

数据为原始 `E题_材料阅读/E题数据` 附件2和附件3的对齐版本；不读取附件4。通用冻结文本资产为 `step1/assets/distilbert`，模型 `distilbert/distilbert-base-uncased`，修订 `12040accade4e8a0f71eabdb258fecc2e7e948be`，权重SHA256 `5e3f1108e3cb34ee048634875d8482665b65ac713291a7e32396fb18f6ff0063`。其来源见[官方模型卡](https://huggingface.co/distilbert/distilbert-base-uncased)。该约256MiB的通用权重不纳入50MB结果包。

## 文件职责

| 文件 | 职责 |
|---|---|
| prepare.py / data.py / dynamic.py | 题目接口审计、词表全量核对、有效掩码、训练统计、逐轮原始token删除 |
| model.py | 多头自注意力、跨模态注意力、空输入兜底及对照模型 |
| legacy_model.py | 旧版TCN门控的只读比较实现 |
| train.py / engine.py | 三种子训练、早停、概率/强度集成和统一指标 |
| evaluate.py / selection.py | 完整验证矩阵、注意力候选锁定、旧门槛对照与锁定后测试 |
| infer.py | 附件3全量预测、固定验证样本的内部注意力展示 |
| verify.py | 掩码不泄露、注意力合法连接、有限梯度和全空兜底检查 |
| report.py / package.py | 报告、图表、审阅页面、完成核验和交付包 |

为了复用已有计算，首次运行的干净训练/六个验证视图通过新目录中的符号链接只读读取 `step2/cache`。逐轮和完整评价视图可读取 `step2_v2/cache`，键包含输入/encoder/统计/场景信息并检查mask一致；不复用其预测作为新模型预测。缓存缺失时能够重新编码生成，不需要复制旧目录的大型缓存。本轮逐轮只保留两个视图的内存缓存，不新建数十GB特征缓存。

旧版比较权重已复制到本目录 `checkpoints/old_gated_*.pt`。`source_reuse.json`记录复用代码的来源哈希。新注意力模块和训练权重独立，不覆盖历史模型。

## 可执行流程

从项目根目录执行；先确认所选GPU空闲。当前服务器示例：

```bash
export CUDA_VISIBLE_DEVICES=1
export OPENBLAS_NUM_THREADS=1
export OMP_NUM_THREADS=1
export TOKENIZERS_PARALLELISM=false
PYTHON=/usr/local/python3.10/bin/python3
$PYTHON step2_attention/prepare.py
$PYTHON step2_attention/verify.py
$PYTHON step2_attention/train.py --seed 17
$PYTHON step2_attention/train.py --seed 29
$PYTHON step2_attention/train.py --seed 43
$PYTHON step2_attention/evaluate.py --split valid
$PYTHON step2_attention/selection.py
$PYTHON step2_attention/evaluate.py --split test
$PYTHON step2_attention/infer.py
$PYTHON step2_attention/report.py
$PYTHON step2_attention/package.py
```

三个种子也可在各自已确认空闲的GPU上独立运行。相同名称的已完成拟合经过协议/权重哈希核验后跳过；中断的单次拟合从该拟合起点重跑，不支持恢复优化器中间状态。重新更改配置实验应新开目录或先备份旧结果，不能把完成标记与新配置混用。

推理只需要已生成的 `protocol.json`、`selection_lock.json`、标准化参数、被选中的三个检查点、冻结编码器及原始附件3；不依赖训练缓存。运行 `infer.py` 还会读取附件2验证样本生成内部注意力图的原始矩阵。

## 输出和统计解释

- `results/valid_metrics.csv`：所有新配置和旧版参考的三种子、集成、217输入实现的验证指标。
- `results/test_metrics.csv`：选择锁定后的旧版/注意力候选测试复核。
- `results/selection_comparison.csv`：六场景J、完整与缺失表现、中性及强情感误差。
- `results/*_predictions.npz`：`out[场景,种子,样本,4]`，最后一维前三项为类概率、最后一项为连续强度；同时保存样本ID和真值，仅内部评价使用。
- `results/附件3_注意力模型预测.csv`：30条，`sample_id,polarity,intensity`，极性为negative/neutral/positive。
- `results/附件3_预测审阅.csv`：概率、种子间分歧、观测比例；未经置信度校准。
- `results/attention_clean.npz`、`attention_missing.npz`：cross种子17的固定验证样本内部注意力；若cross不是被选中模型，图上仍明确标注该对照结构。

Macro-F1按负向/中性/正向三类计算；另报Accuracy、Weighted-F1、MAE、Pearson、中性召回。强负向为真实强度≤−1.5、强正向为≥1.5。不同训练种子和不同人工遮挡重复分别汇总，不能当作独立样本重复扩大样本量。

本轮是新的注意力尝试，并不预设优于旧方法。若未通过既有替换门槛，报告会明确说明；新预测仅作为注意力方案的独立结果保留。
