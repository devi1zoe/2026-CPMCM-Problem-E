# 问题二后续四组实验

本轮沿用原有数据划分、缺失定义和七项替换标准。训练 3395 条、验证 728 条；历史测试 727 条已经在过去使用过，不视为新的独立验证。附件3只在选定方案后预测。

1. **缺失形状**：比较单段训练、单段与多段各一半、再允许不同模态缺失比例不同。单段与多段保持删除总数相同。各方案一半训练输入完整，其余从七种模态组合、四种比例和四种位置抽取。模型及其他训练条件相同。
2. **文本理解**：比较不调整与少量调整文本模型，分别用于纯文本和三模态预测。采用原有单段缺失训练，先检验文本改善及其对多模态的帮助。词元先删除，再计算文本表示。
3. **可靠性融合**：比较只看缺失程度、增加预测把握与模态分歧、再增加有限强度修正。训练内部按源视频分组，用没有见过相应样本的模型产生预测，再学习融合。检查纠正文本错误的数量和破坏文本正确判断的数量。
4. **缺失特征估计**：比较不估计与估计缺失位置低维特征。只以人工删除前确实存在的特征作为答案；原本缺失的位置不参与重建误差计算。估计值与实际观测分开，以最终情感预测成绩判断是否有用。

每种方案独立训练三次（17、29、43），相同对照使用相同遮挡。分类主要看 Macro-F1，强度主要看 MAE，另报准确率、相关系数、中性识别率及强正负情感误差。完整输入、原有单段缺失、多段缺失、错开缺失、不等长缺失分别汇总；单独报告涉及文本缺失的场景。

每组先独立比较，再决定保留。仅在单项改动都得到支持时，进行一项组合实验。全部结论允许“有效”“无收益”“证据不足”，不得把负结果改写成成功。正式替换仍需同时满足：完整 F1 下降≤0.005、完整 MAE 增加≤0.01、原有缺失平均 F1 提高≥0.01、缺失 MAE 不增加、中性识别下降≤0.01、强正与强负 MAE 分别增加≤0.02。

补充说明：多段缺失按三个分区分配，极短样本可退回单段，相邻段可能连接；不等长训练各模态独立抽取同一组四档比例，起点按相同位置类别抽取，但不要求相同。新实验全部保存在本目录，历史四组实验和问题三不改动。
