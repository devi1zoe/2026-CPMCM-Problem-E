# 固定窗口对照箱线图

三图由 `plot_window_statistics.py` 使用Python Matplotlib绘制。中文为SimHei，英文数字为DejaVu Sans；统一用蓝色表示0.2秒短窗、暖橙色表示0.5秒长窗，线条、文字及统计标记为黑色，采用普通坐标框。

| 文件 | 样本数 | 均值：短窗 / 长窗 |
|---|---:|---|
| `figures/fig_p1_audio_window_error.pdf` | 100 | 0.5449 / 0.7467 |
| `figures/fig_p1_vision_window_error.pdf` | 87 | 0.2357 / 0.4373 |
| `figures/fig_p1_word_crossing_ratio.pdf` | 79 | 71.33% / 39.50% |

图内仅保留坐标与窗口标签、样本数、箱线分布和均值标记，去掉顶部解释句、底部重复的均值数值及箱线图说明；具体均值保留在上表。箱体表示中间50%的样本，箱内横线为中位数，黑色菱形为均值，箱外圆点为离群值；所有离群值及零值仍参与统计。重建误差先按样本计算；词跨界比例也先在样本内计算，再对79条适用样本等权平均。此次精简不修改统计口径、样本选择或数据。

在附件根目录运行：

```bash
python step1/paper_results/plot_window_statistics.py
```

程序优先读取同目录的 `audited_window_comparison.csv` 和 `data_audit.json`；提交附件中自动读取 `step1/validation/` 下的同名文件。依赖NumPy、Matplotlib及已随附的 `step1/paper_5_2/figure_style.py`、字体注册函数和SimHei字体，无需GPU、模型或原视频。

输出PDF至 `figures/`，本地PNG预览至 `previews/`，核对记录至 `window_figures_manifest.json`。每次重绘均核对两种窗口的样本集合，以及样本数、均值、中位数、四分位数和离群点数量，确保与既有审计结果一致。完整工程的 `build_publication_figures.py --window-statistics-only` 也可单独重绘三图。
