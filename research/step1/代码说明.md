# 问题一代码说明

本目录只处理附件1的100条原始视频与给定转写。不读取附件2～4，不训练情感预测模型，不开展问题二或问题三实验。关键函数均有中文说明。

## 1. 实现与原思路的对应

采用“原文词级强制对齐＋时间交叠聚合”为主流程，增加0.2秒和0.5秒固定窗口对照。所有输入样本、原文和标签保持不变。

| 环节 | 实际实现 | 相对思路文件的说明 |
|---|---|---|
| 媒体读取 | PyAV解码MP4；音频转16 kHz单声道；视频记录真实PTS | 不使用帧号除以帧率替代已有PTS |
| 词级对齐 | 冻结`facebook/wav2vec2-base-960h`声学模型＋标准CTC Viterbi路径 | 思路以MFA为例，实际采用无需另配词典的CTC强制对齐；仍是给定转写约束的显式对齐 |
| 文本 | 冻结`distilbert/distilbert-base-uncased`，768维 | 通用英文预训练模型，没有用其他情感数据集训练或微调 |
| 声学 | openSMILE eGeMAPSv02的25维低层描述量 | 保留工具输出的窗口起止时刻；维度不强凑为附件2的74 |
| 视觉 | MediaPipe Face Landmarker的52维blendshape系数 | 替代OpenFace以便部署；blendshape不等同于FACS动作单元，也不是情感类别概率 |
| 时间聚合 | 按词区间与有效音视频帧区间的交叠长度加权 | 无有效观测时保留该词位置、零向量及False掩码 |
| 窗口对照 | 0.2秒、0.5秒 | 比较信息平滑与词跨窗口边界情况，不用该对照宣称情感预测性能提升 |

预训练模型只用于冻结特征提取与声学对齐。Wav2Vec2的贪心识别结果单独保存为诊断，绝不覆盖给定原文。

## 2. 时间、词与掩码定义

英文词按字母、内部英文/弯引号撇号和数字串确定，保留原文字符区间；数字仅在CTC目标副本中展开为英文。原始标点仍参与文本编码；独立标点子词的`word_index=-1`，不会伪造它的发音区间。所有子词表示和offset映射均保留。超过510个子词时才分块，每块加入CLS/SEP，不静默截断。

CTC包含blank、保持、前进一步和合法的跨两状态转移；重复字符必须经过blank。模型卷积步长和感受野决定帧中心，代码从配置推导时间，不采用序列位置占比乘视频时长。每个词的起止为该词发音字符占据的首尾帧边界；不把词间静音强行填给词。

词置信度为路径上发音字符后验概率的几何平均。`0.1`是预先设定的质量提醒阈值，不是校准后的正确率阈值，低分词不会被删除。对齐无法产生完整路径时保留词、零时间数组和`alignment_valid=False`，JSON起止时间为`null`，不会均匀分配时间冒充对齐结果。

视频以5 Hz目标频率抽样，保存实际选中帧的PTS和原帧索引。相邻抽样PTS中点构成近邻保持时间单元；这是明确的离散近似，并非证明表情在整个单元内恒定。检测阈值和人脸存在阈值均为0.5，最多检测2张脸，多脸取面积最大者并记录数量。最大人脸是否为说话者未被验证。无人脸处视觉零向量只是占位，必须结合掩码读取。模型没有返回可直接保存的最终检测置信度，不能将blendshape分数当作检测置信度。

声学采用工具返回的原生窗口，静音用窗口RMS低于0.0031623（约−50 dBFS）标记。这仅指低能量，不等于不存在音频，也不等于严格的语音活动标注。音频覆盖缺口、非有限特征另设无效掩码。表情系数、音高等是潜在情感线索，不直接证明真实情绪。

对词区间$I_k$、原始特征帧支持区间$J_j$和可观测标记$O_j$：

$$a_{kj}=\frac{|I_k\cap J_j|O_j}{\sum_r|I_k\cap J_r|O_r},\qquad x_k=\sum_j a_{kj}x_j.$$

分母为零时权重行、聚合向量均为零，并设置可观测标记为False。声学窗口可重叠，分母是交叠权重之和，不是有效时间区间的并集长度，不能把它误称为覆盖率。

每条样本采用变长数组，位置数等于保留的原文词数，不补齐到50；因此没有存储填充或长度截断。`alignment_high_confidence`、`alignment_valid`与三模态的`*_valid`意义不同，不能混用。

## 3. 文件与输出

| 文件 | 用途 |
|---|---|
| `config.json` | 预先设定的参数及存储规范 |
| `common.py` | 100条标签与视频一一对应检查、路径、哈希、项目依赖加载 |
| `alignment.py` | 原词/字符映射、CTC路径、词界、交叠聚合 |
| `features.py` | 真实音视频解码及三模态特征提取 |
| `run.py` | 全量提取、失败日志和受哈希约束的断点续跑 |
| `analyze.py` | 100行/300行汇总、窗口对照、可视化与本地回看页 |
| `verify.py` | 全量独立复算时间权重、验证CTC路径、输入/代码哈希及特征 |
| `test_alignment.py` | 穷举路径对照、重复字符、不可行路径、缺失掩码测试 |
| `download_assets.py` | 固定commit的模型获取及SHA256记录 |
| `audit_media.py`、`preview_sources.py` | 全量声画解码核验、100条视频实际中点帧总览 |
| `build_report.py` | 从真实结果和全量核验生成实验结果文档 |
| `quality_audit.py` | 转写一致性风险清单、保守时间使用掩码及阈值敏感性检查 |
| `package_results.py` | 排除模型和环境的结果包、文件哈希清单及体积检查 |
| `check_reproducibility.py` | 两条独立试跑与正式提取结果逐字段比较 |

每条样本在`results/samples/<video_id>$_$<clip_id>/`下保存：

- `features.npz`：`text/audio/vision`分别为`(词数,768/25/52)`；三模态有效掩码、词时间与置信度；原生声学/视觉特征与时间；子词特征与映射；交叠权重；CTC发射概率、路径和目标字符。
- `metadata.json`：原文、原始标签、源文件哈希、全部词与子词位置、特征名称、异常状态、运行耗时、处理代码/配置哈希。
- `contact_sheet.jpg`：6张实际视频抽样帧，带真实PTS。
- `windows_0.2s.npz`、`windows_0.5s.npz`：固定窗口声学/视觉特征、掩码、文本词权重；文本窗口表示由`text_word_weights @ features['text']`精确重建，避免重复存储768维矩阵。
- `quality.json`、`quality_masks.npz`：片段转写一致性风险及保守时间使用掩码。原始候选对齐仍保留；涉及时间使用时应优先使用这些额外掩码，而不是把`text_valid`等内容存在性标记误当作时间可靠性。

`results/sample_summary.csv`是一行一个样本；`modality_summary.csv`是一行一个样本的一种模态，共300行；`word_alignment.csv`列出所有词时间与状态。`metrics.json`保存真实统计，`window_comparison.csv`保存200条窗口对照结果，`verification.json`保存全量核验。

读取示例：

```python
from pathlib import Path
import numpy as np
sample = next(Path('step1/results/samples').iterdir())
with np.load(sample / 'features.npz', allow_pickle=False) as data:
    text = data['text']
    audio = data['audio']
    vision = data['vision']
    seconds = data['word_bounds']
    # 无脸、无有效观测的占位零必须结合mask使用。
    vision_observed = data['vision_valid']
```

## 4. 运行与环境保护

遵循`~/.bashrc_hyf`中的共享解释器配置，GPU推理使用`/usr/local/python3.10/bin/python3`和根环境的PyTorch 2.5.1+cu121。只在已有`step1/.venv`安装补充依赖；`common.py`为本进程添加其site-packages。没有安装、升级或替换根环境的PyTorch/CUDA，也不向根环境安装项目依赖。

项目venv于收到补充环境说明前建立，此后复用同一环境，没有再创建环境。`requirements-project.txt`锁定补充依赖；实际完整包版本记录在`results/environment.json`及环境清单。模型文件哈希记录在`assets_manifest.json`及环境记录中。

在工作区根目录运行；GPU命令应在允许访问GPU的沙箱外执行。`CUDA_VISIBLE_DEVICES=3`对应当次空闲卡，设备被进程映射为`cuda:0`；复现时先核对该卡是否仍空闲。

```bash
# 仅在既有项目venv缺依赖时执行，禁止替换成根环境pip。
step1/.venv/bin/python -m pip install -r step1/requirements-project.txt
/usr/local/python3.10/bin/python3 step1/download_assets.py
/usr/local/python3.10/bin/python3 step1/audit_media.py
/usr/local/python3.10/bin/python3 step1/preview_sources.py

# 轻量单元测试可在沙箱中进行。
/usr/local/python3.10/bin/python3 -m unittest discover -s step1 -p 'test_*.py' -v

# 少量试跑；不把试跑输出当全量结果。
CUDA_VISIBLE_DEVICES=3 /usr/local/python3.10/bin/python3 step1/run.py --device cuda:0 --limit 2 --output step1/smoke

# 正式100条处理；配置、代码、源视频哈希一致才复用已有样本。
CUDA_VISIBLE_DEVICES=3 /usr/local/python3.10/bin/python3 step1/run.py --device cuda:0 --resume
/usr/local/python3.10/bin/python3 step1/check_reproducibility.py
/usr/local/python3.10/bin/python3 step1/quality_audit.py
/usr/local/python3.10/bin/python3 step1/analyze.py
/usr/local/python3.10/bin/python3 step1/verify.py
/usr/local/python3.10/bin/python3 step1/build_report.py
/usr/local/python3.10/bin/python3 step1/package_results.py
```

预训练模型使用确定版本：Wav2Vec2 `22aad52d435eb6dbaf354bdad9b0da84ce7d6156`；DistilBERT `12040accade4e8a0f71eabdb258fecc2e7e948be`；MediaPipe模型下载路径固定为float16版本1。训练参数不存在，因为本问所有神经网络均冻结，仅做推理。随机种子20260923；具体GPU、时间和版本以实际环境记录为准。

`results/alignment_review.html`提供100条本地视频回看，必须保留赛题解压目录的相对位置。点击词按钮可跳转并播放。直接打开HTML的浏览器若限制本地媒体，可从工作区根目录运行`python3 -m http.server 8000`后访问`http://localhost:8000/step1/results/alignment_review.html`。

## 5. 验证边界与参考

真实试验发现部分原文与声学识别结果有明显不一致信号。为避免把合法CTC路径当成正确时间，增加保守质控规则：平均词置信度<0.2、低于0.1的词超过半数、或诊断WER>0.8，任一满足则整条样本进入转写复核清单。阈值是在检查实际异常后制定的质量规则，没有用情感标签或预测成绩调参，也没有人工词界真值校准；另报告均值阈值0.1/0.2/0.3与WER阈值0.6/0.8/1.0的敏感性结果。未触发规则也不保证时间正确。

风险样本的`timing_usable`全False；其他样本仅置信度至少0.1的有时间词为True。固定窗口的文本权重只使用此保守掩码，无法可靠放置的文本不强行分配时间，原文及词/子词向量仍完整保存；窗口声学和视觉不依赖转写，照常输出。风险不等于证明原标签错误，不能据此改标签或替换转写。

模型载入日志中可能提示`wav2vec2.masked_spec_embed`未从权重初始化。已核对所用Transformers源码，该参数仅用于训练时的掩码增强或显式提供掩码时；本代码使用`eval()`且不传入该掩码，因此它不参与本次推理。没有因该提示额外训练模型。

独立核验通过，只证明样本完整、路径合法、时间记录和聚合计算自洽。赛题未提供人工词级时间真值，因此不能报告真实词界误差或声称达到某个对齐准确率。贪心ASR的词错误率只是转写一致性诊断，不能代替强制对齐精度。固定窗口重建MSE也不是情感识别性能。
