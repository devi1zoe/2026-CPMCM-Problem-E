# 声学与视觉实例配图

两张图由Python Matplotlib绘制，中文使用SimHei，英文数字使用DejaVu Sans。字体与柔和配色由 `../paper_5_2/figure_style.py` 设置，沿用既有子图、时间范围、原生观测值和缺失标记。

- `figures/fig_5_3_acoustic_example.pdf`：原始波形为蓝色，响度为青蓝，半音基频为暖橙，MFCC1为柔紫；砖红标出两处取值。F0零值按原规则留空，不补造基频。
- `figures/fig_5_3_visual_example.pdf`：保留四帧真实视频画面。张嘴系数为青蓝，嘴角和眼睑系数均用蓝色实线表示左侧、橙色虚线表示右侧；有效观测为青绿方块、缺失为砖红叉号。缺失处保持断线，三个系数面板均保留0—1纵轴。

在附件根目录运行：

```bash
python step1/paper_5_3/build_acoustic_example.py
python step1/paper_5_3/build_visual_example.py
```

脚本读取 `step1/results/samples/` 中的既有特征。声学样本由 `step1/results/figure_samples.json` 指定；视觉样本为 `-wny0OAz3g8$_$9`。实际音频波形和四幅视频帧从赛题原视频解码，因此重绘这两张图需要按附件根目录《复现实验说明.md》的输入目录准备原始附件1。依赖NumPy、Matplotlib、PyAV、Pillow和随附的SimHei字体，复用原环境，无需GPU或模型权重。

默认输出PDF；如需本地预览，可添加 `--preview <PNG路径>`。`*_example_values.csv` 与 `*_example_manifest.json` 记录对应观测值、时间和来源。此次样式调整不重新提取特征，不改动NPZ。
