# 问题二优化代码说明

## 环境与输入

使用 `/usr/local/python3.10/bin/python3` 的原有 PyTorch 2.5.1+cu121；通过 `common.py` 复用 `step1/.venv/lib/python3.10/site-packages` 中现有依赖。已阅读 `/home/ubuntu/.bashrc_hyf`，没有安装、升级、降级或创建环境。

原始附件位于项目根目录 `E题_材料阅读/E题数据`。统一使用附件2/3对齐版本；不修改原始文件。编码器沿用 `step1/assets/distilbert`，来源为 `distilbert/distilbert-base-uncased`，修订 `12040accade4e8a0f71eabdb258fecc2e7e948be`，权重SHA256 `5e3f1108e3cb34ee048634875d8482665b65ac713291a7e32396fb18f6ff0063`。通用权重约256MiB，不在50MB交付包中，复现需准备该固定资产；不得替换为情感数据微调模型。

## 运行

在项目根目录执行，物理GPU编号必须先检查占用。本轮最初GPU2/3空闲，GPU3后被外部任务占用，主编排转至GPU2；GPU3再次空闲时用于提前验证已完成的配置。不终止其他任务。编排脚本只适用于GPU2已确认可用的当前服务器，换机器须调整脚本设备分配。

```bash
export CUDA_VISIBLE_DEVICES=2
export OPENBLAS_NUM_THREADS=1
export OMP_NUM_THREADS=4
PYTHON=/usr/local/python3.10/bin/python3
$PYTHON step2_v2/prepare.py
$PYTHON step2_v2/verify.py
$PYTHON step2_v2/run_all.py
```

编排顺序：三组回归权重预实验→锁定权重→十模型各三种子→完整验证→注册候选逐项移除消融→消融拟合/验证→最终模型锁定→一次测试复核/分组bootstrap→附件3推理→报告和打包。

单任务可使用：

```bash
$PYTHON step2_v2/train.py --seed 17 --names aux msd cce imtd emc
$PYTHON step2_v2/evaluate.py --names old_gated gated cce
$PYTHON step2_v2/selection.py
$PYTHON step2_v2/selection.py --final
$PYTHON step2_v2/bootstrap.py
$PYTHON step2_v2/infer.py
```

最终选择前测试脚本拒绝运行；选择后仅允许锁定文件列出的比较模型。脚本不根据测试结果改参数。附件3无标签，仅最终推理。

## 推理数值与性能

原设备上的确定性cuDNN时序卷积较慢。`inference_ops.py` 以显式滑动窗口和FP32线性运算实现相同卷积，先用float64核对填充与膨胀率的代数等价，再对每个模型的六个固定验证输入比较原预测与新预测。最大绝对差须≤1e-3、集成分类必须完全一致，否则该模型仍使用原cuDNN。后端选择不使用真实情感标签。

记录见 `results/backend_*.json`；约1e-4的差异主要涉及数值执行精度，不能宣称位级一致。训练卷积、训练验证早停和六场景J保留原cuDNN计算；完整压力矩阵使用经核验的后端，旧模型也按相同规则复算。部署清单锁定所选后端，独立解压后的预测必须与交付CSV一致。

## 缓存、重跑与并发

每个样本的遮挡由 `SHA256(seed/global_epoch/sample_id)` 生成，与模型和标签无关。缓存键覆盖原词元、注意力、有效位置、文本观测掩码及冻结编码器哈希。文件写入先临时文件后原子替换；相同训练任务与缓存均使用文件锁，避免并发覆盖。

完整训练视图和六验证视图可以复用旧版缓存；交付包不包含缓存，缺失时可从原附件重建。只复用训练集标准化统计。缓存总量较大，只是本地加速文件，不计入交付。

完成标记包括权重哈希、配置和回归权重。已完成任务验证哈希后跳过；未完成的单次拟合从起点重新训练，不宣称恢复优化器中断状态。模型选择文件已存在时必须内容一致，不允许静默覆盖。改模型或协议请使用新实验目录；当前代码及协议在打包时统一保存SHA256。

## 输出与复现边界

`results/附件3_问题二预测.csv` 为30行标准结果，列 `sample_id,polarity,intensity`；审阅文件另含概率、种子标准差及可用率。训练专用教师无需交付，辅助头在导出时移除，部署权重在 `deployment/`。

联合交付包保留问题一和问题三已有成果、问题二新版最终推理材料，以及问题三从头训练确实需要的旧问题二门控初始化权重。旧版其他消融权重仍在工作区，联合包内提供原训练代码、配置、检查点选择记录及重训说明。重新运行旧问题三的全候选比较前，需先按原 `step2/train.py` 重建其余旧候选权重。

不要把联合包覆盖解压到现有工作区。应在独立目录解压，并提供原附件、固定编码器和相同环境。`predict_package.py` 从打包权重独立重算30条专项预测；打包器会实际执行并逐项核对。旧版问题二/三文件保护由打包前SHA256全量核查。

完整验证报告、三种子消融、失败验收项、形状/同步性影响、错误案例和视频分组区间均保存在 `results/`。本轮不重训问题三，新的融合权重也不作为问题三解释结果。
