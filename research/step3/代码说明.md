# 问题三复现说明

本目录完成可解释预测、验证集实验、附件4全量20条预测与解释、原素材时间映射及离线审阅页。模型定义见 [模型定义.md](模型定义.md)，实际结果见 [问题三实验报告.md](问题三实验报告.md)。

## 环境与依赖

复用根Python `/usr/local/python3.10/bin/python3`、PyTorch 2.5.1+cu121，以及既有 `step1/.venv` 中的transformers 4.48.3等依赖。没有新建环境，也没有升级或替换根环境包。精确版本和冻结模型信息见 `environment.json` 及 `step1/assets_manifest.json`。

冻结模型复用既有资源：

- DistilBERT：`distilbert/distilbert-base-uncased`，修订 `12040accade4e8a0f71eabdb258fecc2e7e948be`，768维，最多50槽，完整冻结。
- Wav2Vec2：`facebook/wav2vec2-base-960h`，修订 `22aad52d435eb6dbaf354bdad9b0da84ce7d6156`，16kHz单声道，仅用于给定原文的CTC时间估计与诊断识别。

附件4以NumPy2内部模块名序列化，现有NumPy1.26直接读取会报 `numpy._core.numeric` 不存在。`CompatUnpickler` 只将该模块前缀映射至现有 `numpy.core`；不安装新NumPy，不修改原始pkl。

## 文件与顺序

| `explain.py` | IG、自适应数值积分、原token删除重编码及局部探测 |

| `package.py` | 要求审计、哈希清单、压缩包及三问累计大小检查 |

完整重训应先把旧 `step3` 结果、权重和锁文件备份。不要将旧完成标记与人工修改的配置混用。模型推理和专项解释不需要再次训练。

## 数据与训练

使用附件2对齐版，训练3395、验证728。参数只在训练集更新；问题二已训练权重作为初始化，问题三按完整验证集的 `MAE+1−MacroF1` 选择。附件2测试集已在问题二使用，本问不把它冒充新的盲测集，也不使用它重新调参。附件4没有标签，只用于最终预测、解释与原素材回看。

训练最多20轮，lr=0.0003，AdamW，weight decay=0.001，batch64，dropout0.2，隐藏64，早停耐心5。80%完整输入、20%在7个真子模态集合中均匀抽样，包括空集合。微调保留epoch0候选，实际最佳轮次见训练日志，不能假定每个种子都采用微调后的参数。

训练统计沿用问题二训练集标准化；解释敏感性参考值为训练可观测位置的逐维中位数。若问题二缓存存在则只读复用；交付包不含该缓存时，`prepare.py` 会在 `step3/cache` 重建必要的完整输入特征，不改写问题二。复现需要原始附件、问题一的冻结模型资源，以及问题二交付的初始权重和标准化统计。

## 解释规则与数值检查

分类解释固定完整输入的原预测类别概率；强度另作Shapley。三个模态共8个组合，完整保留每个组合、每个种子的输出，逐样本检查贡献总和等式。CSV中的 `contribution_*` 是有符号分类贡献；绝对贡献占比另见详细结果，不能把负贡献当支持。

主局部预算是有效词槽20%，按半向上取整且至少1槽。IG只在连续表示层排序；文本删除验证必须在冻结编码器之前修改token与attention。验证集使用5个等长随机窗口；同时评价保留指定模态局部且其他模态完整，以及仅保留这一个局部、其余模态都不可用两种条件。

32节点积分未对所有样本达到要求，因此加入由完备性残差驱动的64/128/256节点加密，绝对容差0.001。规则和原因保存在 `numerical_protocol.json`；不使用真实标签、删除效果或专项结果选数值积分节点。原32节点误差与修正结果都保留。

专项局部窗口被全部探测，解释卡给出IG候选与最终确认的强影响窗口。穷举最大删除效应本身不能作为独立忠实性证明；独立随机对照来自验证集上先IG排序、再原输入验证的程序。

小噪声稳定性是标准化表示上的0.02标准差高斯扰动；不同种子和基线可能产生不同证据，不能将一个条件下稳定写成普遍稳定。分数、随机对照和不利案例全部保留。

## 结果读取

`results/附件4_问题三预测与解释.csv` 恰好20行，字段：

```text
sample_id,polarity,intensity,main_modality,contribution_text,contribution_audio,contribution_vision,evidence
```

`sample_id` 为原始两位文件编号，读取时指定字符串。`evidence` 是合法JSON数组，每个模态包括半开区间 `[slot_start,slot_end)`、原文字符范围、片段、固定目标分数差、强度变化、方向、IG候选，以及估计/候选时间状态。所有槽和字符索引均从0开始。

```python
import json
import pandas as pd
table = pd.read_csv('step3/results/附件4_问题三预测与解释.csv', dtype={'sample_id': str})
evidence = json.loads(table.loc[0, 'evidence'])
```

`results/special_explanations.json` 是完整解释卡数据；`cards/` 包含逐样本JSON和真实视频帧；`mapping/` 包含原文、诊断ASR、CTC词/子词时间、置信度与媒体哈希。`special_local_effects.csv` 给出每个滑窗的有符号效应。

## 时间定位与复核

所有视频实际解码，原文不被ASR替换；ASR只作匹配诊断。CTC区间为估计值，依据原题的对齐位置对应和子词重复一致性将音视频槽连接到文本词，不宣称拥有官方特征提取时间。

15号转写与所配视频存在明显不一致信号，16号触发整句ASR匹配复核；部分其他样本的局部词也可能低置信。此时 `start_seconds/end_seconds` 为null，候选区间单独保存。仍提供原文字符与特征槽证据，不能自行补全不存在的可靠时间。若无可靠视觉区间，图片只是全片浏览帧，明确不是已定位证据。

`results/explanation_review.html` 可筛选类别、主要模态、时间复核状态，点击区间回看原视频。保持原始解压目录的相对位置；浏览器限制本地媒体时，在工作区根目录运行：

```bash
/usr/local/python3.10/bin/python3 -m http.server 8000
```

然后访问 `http://localhost:8000/step3/results/explanation_review.html`。页面无需外网或CDN。
