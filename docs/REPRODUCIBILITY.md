# 复现导航

## 1. 只阅读结果

阅读 [论文](../paper/paper.pdf)，查看 [问题一字段定义](../submission/问题一提交附件/特征字段与读取.md)、[问题二预测](../submission/问题二提交附件/附件3_问题二预测.csv) 和 [问题三字段说明](../submission/问题三提交附件/结果字段说明.md)。问题三 HTML 下载后本地打开即可使用。

## 2. 核验已提交文件与数值

在仓库根目录执行 `python3 submission/核验总附件.py --files-only`，仅依赖标准库。安装 `requirements-verify.txt` 后执行 `python3 submission/核验总附件.py`，可复核样本、预测字段、解释恒等式和已保存的数值记录。

该入口不需要下载数据、GPU、模型训练或网络；成功仅说明交付一致性及相关数值检查通过，不意味着在新硬件上重训得到了相同结果。

## 3. 固定模型重新预测

- 问题二：按[代码与复现说明](../submission/问题二提交附件/代码与复现说明.md)准备附件 3 和固定版 DistilBERT；使用 `代码/predict.py` 读取已提交三种子权重，另存 CSV 后由核验程序比较。参考容差为强度绝对差 `1e-3`，类别一致。
- 问题三：按[复现说明](../submission/问题三提交附件/复现说明.md)设置输入与资源目录，使用 `初始化复现.py` 创建工作副本，再执行 `step3/infer_special.py`。该过程还需要附件 4 原视频。若重算时间定位，额外准备 Wav2Vec2 并运行 `step3/map_media.py`。专项复算容差为 `1e-4`，同时要求类别、主要模态、证据窗口和时间状态一致。

不要在原提交结果上覆盖写入。问题二的 `P2_WORKDIR`、问题三的 `P3_WORKDIR` 应指向独立目录。

## 4. 从原始输入重新计算或训练

- 问题一：参考[提取流程](../submission/问题一提交附件/复现实验说明.md)，准备附件 1，获取锁定资源，执行媒体审核、两条试跑、100 条正式提取及统计检查。原有两条重复提取最大差为 0，只覆盖那两条样本。
- 问题二：默认 `prepare.py → train.py → evaluate.py` 重现 16 次主实验拟合。仅指定 `--variants gated_aug` 可训练最终结构，但不会生成完整消融比较需要的选择锁。
- 问题三：使用 `初始化复现.py --training` 准备训练工作区，按说明运行训练、解释验证和专项预测。正式包提供问题二初始化参数；若要求这些参数也从头训练，须先完成问题二主实验，并设置 `P3_P2_ROOT`。

冻结模型：DistilBERT 固定 revision `12040accade4e8a0f71eabdb258fecc2e7e948be`；Wav2Vec2 固定 revision `22aad52d435eb6dbaf354bdad9b0da84ce7d6156`。按各问资产清单校验，不能仅用模型名称认为版本一致。

## 5. 指标比较前的检查

确认使用相同划分、掩码规则、缺失场景、随机种子、全缺失回退和聚合口径。问题二的原始主实验与最终统一接口分别保留，不混用数值。模型选择仅依据验证集；附件 3、4 无真实标签。历史研究报告的未采用结果不替换正式包中的最终权重。
