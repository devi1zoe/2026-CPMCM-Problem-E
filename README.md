# 华为杯 2026 · E 题：复杂场景下多模态情感预测

本仓库整理了 **2026 年华为杯中国研究生数学建模竞赛 E 题《复杂场景下多模态情感预测的数学建模与算法设计》**的论文、代码、模型、预测结果与实验记录。基于赛题提供的 CMU-MOSEI 英文多模态数据，研究文本、语音与视觉的时序对齐、局部缺失下的情感预测，以及预测证据的解释与追溯。

**先看结果：** [论文 PDF](paper/paper.pdf) · [三问提交总说明](submission/总说明.md) · [问题二 30 条预测](submission/问题二提交附件/附件3_问题二预测.csv) · [问题三 20 条预测与解释](submission/问题三提交附件/step3/results/附件4_问题三预测与解释.csv)

## 仓库提供什么

| 任务 | 方法概要 | 交付内容 |
| --- | --- | --- |
| 问题一：特征提取与时序对齐 | 冻结 DistilBERT、openSMILE、MediaPipe；CTC 候选词界与时间交叠加权聚合 | 100 条样本、1,932 个词位置的特征、质量掩码、时间对应与统计图 |
| 问题二：模态缺失下的情感预测 | 时序卷积、掩码池化、缺失感知门控、连续遮挡增强；分类与回归双任务 | 三种子最终模型、消融及缺失实验、附件 3 的 30 条预测 |
| 问题三：可解释情感预测 | 模态组合增强、Shapley 模态贡献、积分梯度候选与原输入删除验证、CTC 媒体定位 | 附件 4 的 20 条预测、60 条局部证据、关键帧及离线查看页面 |

模型分别输出负向／中性／正向三分类和 `[-3, 3]` 内的连续情感强度。分类结果由分类头确定，不用回归值符号替代。

## 快速开始：无需 GPU 或原始数据

克隆或下载仓库后，在仓库根目录执行。Python 要求 **3.10 或以上**。

```bash
git clone https://github.com/devi1zoe/2026-CPMCM-Problem-E.git
cd 2026-CPMCM-Problem-E
```

```bash
# 仅检查 879 个正式提交文件的大小和 SHA256：只需标准库
python3 submission/核验总附件.py --files-only

# 在独立环境中进行样本、字段与已保存数值的完整核验
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-verify.txt
python submission/核验总附件.py
```

Windows 用户可使用 `py -3` 创建环境，并执行 `.venv\Scripts\Activate.ps1` 激活。

完整核验检查问题一 100 条样本与特征字段、问题二 30 条预测、问题三 20 条预测及 60 条证据，并复算已保存的 Shapley 完备性、728 条 IG 积分残差和 2,184 行删除指标。**这些检查不等于重新提取特征或重新训练模型。**

查看解释时，下载仓库后用浏览器打开 [解释结果查看.html](submission/问题三提交附件/解释结果查看.html)，即可离线查看预测、贡献、证据和图片。GitHub 文件页面显示 HTML 源码；需要本地打开才能交互。播放原视频时，在页面内选择自己的附件 4 视频目录。

## 数据与输入接口

原始赛题数据、公开预训练大模型、运行环境与可重建缓存不随仓库重复分发。完整重跑需自行准备赛题附件，具体目录见各问复现说明。

| 数据 | 用途 | 数量／划分 |
| --- | --- | --- |
| 附件 1：原始视频与标签 | 问题一特征提取 | 100 条 |
| 附件 2：`aligned_50.pkl` 与标签表 | 问题二、三训练和评价 | 训练 3,395；验证 728；测试 727 |
| 附件 3：对齐版缺失特征 | 问题二专项预测 | 30 条，无真实标签 |
| 附件 4：对齐版特征及视频 | 问题三专项解释 | 20 条，无真实标签 |

**问题一与问题二、三使用不同特征接口。** 问题一产生变长词级的 `768 / 25 / 52` 维文本／声学／视觉特征；问题二、三使用官方 50 槽对齐输入，文本 token 经冻结 DistilBERT 得到 768 维表示，声学／视觉分别为 74／35 维。不能把问题一输出直接接到问题二、三模型上。

缺失比例按有效槽位计算，不表示视频秒数。文本遮挡在冻结编码之前进行；标准化统计量仅由训练集可观测位置拟合。附件 3、4 不参与训练或选型，也不报告专项准确率。

## 复现预测与训练

参考实验环境为 Linux、Python 3.10.13、PyTorch 2.5.1+cu121、CUDA 12.1、RTX 4090 D。各问的环境记录和依赖清单随正式包保存；完整推理和训练的依赖多于离线核验。不同硬件与软件版本不保证逐位一致。

| 目标 | 文档入口 |
| --- | --- |
| 从 100 条视频重提取三模态特征 | [问题一复现实验说明](submission/问题一提交附件/复现实验说明.md) |
| 用已提交模型复算附件 3；重训主实验与消融 | [问题二代码与复现说明](submission/问题二提交附件/代码与复现说明.md) |
| 复算附件 4 预测、解释与时间定位；重训组合增强模型 | [问题三复现说明](submission/问题三提交附件/复现说明.md) |
| 区分文件校验、固定权重推理和从头训练 | [复现导航](docs/REPRODUCIBILITY.md) |

例如，复算问题二预测时，在配置好其依赖后运行：

```bash
cd submission/问题二提交附件
python 代码/prepare_encoder.py --output assets/distilbert
python 代码/predict.py \
  --input-dir /path/to/赛题数据/附件3-模态缺失特征样本/对齐版本 \
  --encoder assets/distilbert \
  --device cuda \
  --output 复现输出/附件3_复算.csv \
  --details 复现输出/附件3_复算明细.csv
python 核验附件.py --prediction 复现输出/附件3_复算.csv
```

将 `/path/to/赛题数据` 替换成实际目录。无 GPU 时该预测入口支持 `--device cpu`，但文本编码精度与参考 CUDA 环境不同。问题二训练使用 `P2_DATA_ROOT`、`P2_ENCODER`、`P2_WORKDIR`；问题三使用 `P3_DATA_ROOT`、`P3_SPECIAL`、`P3_ASSETS`、`P3_WORKDIR`，具体命令见上表。重跑输出写入新工作目录，避免覆盖已提交结果和校验清单。

## 主要结果与评价口径

下表摘自正式附件记录，均为 **728 条完整验证集、三种子预测集成**，不是专项测试集准确率。

| 模型 | Accuracy ↑ | Macro-F1 ↑ | MAE ↓ | Pearson ↑ |
| --- | ---: | ---: | ---: | ---: |
| 问题二：最终缺失感知门控模型 | 0.6346 | 0.6055 | 0.5784 | 0.6827 |
| 问题三：模态组合增强模型 | 0.6291 | 0.6046 | 0.5651 | 0.6904 |

来源：[问题二复现说明](submission/问题二提交附件/代码与复现说明.md)、[问题三附件说明](submission/问题三提交附件/附件说明.md)。两模型的训练目标和选型规则不同，应结合相应任务评价。

问题一的 1,932 个词位置中，1,545 个通过对齐质量筛选，1,387 个同时具备三模态观测；这不是人工标注词界的准确率。问题三专项结果为 10 条正向、6 条负向、4 条中性，主要参考模态为文本 17 条、视觉 3 条；这些是预测分布，不代表真实分布。

问题二主实验与最终统一接口的随机遮挡种子和全缺失边界规则有所不同。主缺失统计先对同条件的随机重复取平均，再对 112 个条件等权汇总，不能直接对全部记录行平均。两套结果须分别匹配其协议。

## 后续实验与局限

`research/` 收录注意力模型、后续优化、任务独立融合，以及缺失形状、文本调整、可靠性融合和特征重建等实验。各轮报告均记录新方法未通过全部替换要求，因此正式交付继续使用既有模型；不能将某项指标的提高描述为整体方案已经升级。

Shapley 贡献与门控权重不同，也不表示因果关系。局部证据时间是经检查的 CTC 估计，不是官方特征时间戳；未通过检查的正式时间保持空值。专项穷举选择的最大删除效应不能作为独立忠实性证据，解释有效性另由验证集实验支持。
