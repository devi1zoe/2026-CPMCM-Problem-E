## 统一核验

在本总包根目录运行（Python 3.10及以上）：

```bash
# 仅核验所有文件大小和SHA256，只需Python标准库
python3 核验总附件.py --files-only

# 同时运行三问原有核验，并复算问题三数值记录；需要NumPy
python3 核验总附件.py
```

统一核验无需GPU、原视频或网络。它检查交付文件、样本覆盖、结果字段、记录一致性及已保存数值的复算，不重新训练模型或从原始媒体提取特征。首次合并前核验情况及未标注原始压缩包SHA256见 `合并核验记录.json`；全部合并文件的大小和SHA256见 `总文件校验清单.json`（清单自身除外）。
