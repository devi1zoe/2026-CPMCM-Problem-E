# 八张覆盖率、诊断与固定窗口图

运行 `python step1/paper_results/plot_selected_results.py` 可从随附的既有记录重绘八张PDF及本地PNG预览。只依赖NumPy、Matplotlib、`step1/alignment.py`、`step1/paper_5_2/figure_style.py` 与其字体注册函数及SimHei字体，同时读取 `step1/validation/data_audit.json`（完整工程优先读取本目录的同名审计文件），并与全部样本的原生记录核对。不需要原视频、GPU或模型权重。

中文为SimHei，英文数字为DejaVu Sans，标签14 pt、刻度12 pt；使用普通坐标框与白底，无背景网格。PDF位于 `figures/`，数据核对记录见 `selected_figures_manifest.json`。

| 图名 | 配色与保留的内容 |
|---|---|
| `fig_p1_visual_coverage` | 青绿表示有面部特征、暖橙表示无面部特征；抽样帧与词位置分别使用各自分母，沿用3253/3973和1595/1932的覆盖统计。 |
| `fig_p1_audio_energy_share` | 蓝色表示非低能量、暖橙表示低能量；共77261条声学记录，其中9918条低能量。 |
| `fig_p1_rms`、`fig_p1_rms_zoom` | 蓝色RMS曲线、橙色阈值虚线与低能量点；同一333条记录，其中147条低于阈值。纵轴范围分别为0—0.55、0—0.01。 |
| `fig_p1_ctc_confidence` | 青绿色直方图、砖红阈值线；1932个词，保留0—1范围的20个等宽分箱与0.1阈值。 |
| `fig_p1_diagnostic_wer` | 蓝色直方图、砖红阈值线；100条样本，保留0—2范围的20个等宽分箱与0.8阈值。 |
| `fig_p1_window_reconstruction` | 青蓝色原生响度记录，蓝色0.2秒窗口重建，橙色0.5秒窗口重建；展示1.8—3.6秒。 |
| `fig_p1_word_window_overlap` | 蓝色0.2秒窗口、橙色0.5秒窗口，青绿色successful候选区间与边界；分别交叠4个、2个窗口。 |

两个固定窗口图共用蓝色表示短窗、橙色表示长窗；窗口交叠图只对有交叠的格子填充浅色。所有数据、阈值、分箱和聚合算法沿用既有实现。置信度和WER为诊断量，不作为真实词界准确率。

完整工程中也可执行 `python step1/paper_results/build_publication_figures.py --selected-style-only`，全量入口重绘后会保留这八张图的新版样式。其他旧图的字体说明以原清单为准，这八张图以独立清单及总清单的 `fonts_by_figure` 为准。

## 原图内容保留

仅调整字体、配色和版式，不删除独立图原有的数量、阈值、图例和解释标注。覆盖图保留3253帧、720帧、1595词、337词，能量图保留67343条、9918条；RMS图保留147/333条、阈值0.0031623、三项图例及低幅值范围提示色带；CTC/WER图保留350个词、21条片段及阈值区域；窗口图保留重建图例、4个窗/2个窗和末窗交叠0.00247秒的箭头说明。

`annotation_preservation_check.json`记录从旧版独立图及导出脚本核对的内容清单。已检查PDF实际提取文字；重绘入口在导出前也检查这些标注，防止后续样式修改再次遗漏。
