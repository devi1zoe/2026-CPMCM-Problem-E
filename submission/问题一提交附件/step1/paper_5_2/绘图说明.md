# 5.2 数据观察统计图

`figures/fig_5_2_duration.pdf` 和 `figures/fig_5_2_transcript_length.pdf` 由 `plot_histograms.py` 使用 Python Matplotlib 直接绘制。时长图采用柔和蓝色 `#4C78A8`，词数图采用暖橙色 `#E69A52`；保留普通四边坐标框、黑色柱边、中位数虚线和默认样式图例，无背景网格。中文使用黑体 SimHei，英文与数字使用默认无衬线字体 DejaVu Sans；坐标标签14 pt，刻度12 pt，图例11 pt。

在提交附件根目录运行：

```bash
python step1/paper_5_2/plot_histograms.py
```

依赖 NumPy、Matplotlib，以及中文黑体 SimHei；英文与数字使用 Matplotlib 自带的 DejaVu Sans。优先复用现有环境。默认仅导出 PDF；可通过 `--formats pdf png svg` 同时生成预览和矢量源文件。绘图不需要 GPU、原始视频或模型权重。

数据为 `data_observation_samples.csv` 中全部 100 条记录。`duration_seconds` 为既有解码审计的片段时长，取视频与音频终点的较大者，以视频流起点为原点；`word_count` 按原文中的字母词及数字串计数，允许词内撇号，标点不单独计词，不是模型子词数。两列可按 `sample_id` 与附件内 `step1/results/sample_summary.csv` 的 `duration_seconds`、`words` 逐条核对。

时长以 3 秒为组距，词数以 5 词为组距，沿用原图分箱。纵轴为样本条数，虚线为中位数（6.722 秒、18 词）。此次更新仅调整绘图样式。

字体文件随附于 `fonts/SimHei.ttf`，来源与SHA256见 `fonts/source.json`。脚本核对字体内部名称为SimHei，不再回退到Noto Sans CJK。字体来源：[MatplotlibChineseFonts](https://github.com/ZongwuWang/MatplotlibChineseFonts)。

## 类别分布与时长—词数散点图

`figures/fig_5_2_label_distribution.pdf` 与 `figures/fig_5_2_duration_words.pdf` 由 `plot_relationships.py` 绘制，复用 `plot_histograms.py` 中的SimHei字体注册函数。字体、画布大小及坐标轴字号与两张直方图一致，采用Matplotlib默认四边坐标框，无背景网格。

```bash
python step1/paper_5_2/plot_relationships.py
```

默认导出PDF，添加 `--formats pdf png svg` 可更新全部本地格式。散点图使用蓝色 `#4C78A8` 圆点，保留100条样本的实际时长与原文词数。类别图按原始 `annotation` 字段统计，负向、中性、正向分别为18、25、57条，依次使用Matplotlib常用红色 `tab:red`、蓝色 `tab:blue`、绿色 `tab:green`，柱顶标注数量与比例。此次仅修改图形样式，统计口径与数据不变。
