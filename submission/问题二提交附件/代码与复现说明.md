# 问题二代码与复现说明

## 1. 环境与外部输入

参考环境为Linux x86_64、Python 3.10.13、PyTorch 2.5.1+cu121、CUDA 12.1、NVIDIA GeForce RTX 4090 D。其余版本列于`代码/requirements.txt`和`配置/environment.json`。在准备好的Python环境中安装依赖：

```bash
python -m pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu121
python -m pip install -r 代码/requirements.txt
```

以下命令均在本附件根目录执行。`/path/to/赛题数据`表示同时包含“附件2-数据集特征文件”和“附件3-模态缺失特征样本”的目录。使用以下原始材料：

- 训练与验证：`附件2-数据集特征文件/aligned_50.pkl`和`label.xlsx`；官方划分为训练3395、验证728、测试727条。
- 专项推理：`附件3-模态缺失特征样本/对齐版本/附件3_01.pkl`至`附件3_30.pkl`。
- 冻结编码器：`distilbert/distilbert-base-uncased`，固定revision为`12040accade4e8a0f71eabdb258fecc2e7e948be`。

已具备问题一同版本编码器时直接指定该目录；否则执行：

```bash
python 代码/prepare_encoder.py --output assets/distilbert
```

下载包含配置、词表与`model.safetensors`，脚本核对`配置/encoder.json`的逐文件哈希。公开权重不参与本问训练或微调。所有数据加载和推理均使用本地文件。

## 2. 直接复算附件3预测

指定一张可用CUDA设备后运行：

```bash
export CUDA_VISIBLE_DEVICES=0
python 核验附件.py
python 代码/predict.py \
  --input-dir /path/to/赛题数据/附件3-模态缺失特征样本/对齐版本 \
  --encoder /path/to/distilbert \
  --device cuda \
  --output 复现输出/附件3_复算.csv \
  --details 复现输出/附件3_复算明细.csv
python 核验附件.py --prediction 复现输出/附件3_复算.csv
```

推理入口校验30个输入文件、编码器权重、三个模型参数与标准化参数的哈希；输出预测CSV和同名`.核验.json`对照记录。正式结果文件保持原样，复算另存。`--device cpu`可在无GPU时运行，但冻结编码器使用FP32，原参考计算使用CUDA FP16，数值可能存在差异；同版本CUDA环境用于对照论文结果。跨硬件比较默认允许强度绝对差不超过1e-3，并要求类别一致。该容差仅用于复算检查，不改变正式预测值。

## 3. 输入、掩码与标准化规则

输入采用对齐版本，单样本`text_bert`形状为(3,50)，三行为token ID、attention mask与segment ID；`audio`为(50,74)，`vision`为(50,35)。pkl专项样本还包含长度为1的批次维。文本不读取附件2预计算`text`，以`text_bert`经同一冻结DistilBERT获得(50,768)的上下文表示，从而与附件3字段保持一致。

有效位置从索引1起，到最后一个attention有效的SEP（ID 102）之前结束，排除CLS、SEP和尾部填充。没有SEP时，以现存词元或视听非零位置推断可见范围并记录不确定状态。50为槽位数；缺失比例描述有效词元槽位比例，不据此推算秒数。

文本可观测要求位于有效范围、attention有效且token不是0、100、101、102、103。音频和视觉以有效范围内该行至少一维非零为可观测。UNK（100）不能提供可恢复语义，但不据此断言发生了人工删除。有效位置、观测可用性、模拟删除记录分别保存；已有零行与新增遮挡不混为同一状态。

遮挡文本时先将对应token和attention清零，再重新进行冻结编码，避免已删除词继续经上下文进入其他位置。声学和视觉遮挡仅改变观测与相应特征。均值和标准差只由训练集可观测位置计算，标准差下限1e-4，逐维标准化后截断到[-8,8]，不可观测行置零；按FP16保存特征，融合网络以FP32运算。`模型/normalization.npz`内为`text_mean/text_std`、`audio_mean/audio_std`、`vision_mean/vision_std`六个数组。

每种模态还构造三个质量量：观测槽位比例、最长连续缺失长度除以有效长度、有效长度除以48。分支内卷积使用有效位置掩码，池化使用观测掩码；全部不可观测的模态不作为有效门控来源。

## 4. 最终模型及参数

三种模态分别投影到64维，经两层残差一维卷积（核长3，膨胀系数1和2）、LayerNorm与Dropout（0.2）形成时序表示。注意力池化与均值池化拼接后映射为64维，叠加质量量映射；共享门控对可用模态分配权重，融合后输出三分类logits和经3×tanh约束的连续强度。

训练使用带类别权重的交叉熵与SmoothL1（beta=1）之和；类别权重为`sqrt(N/(3*N_k))`并归一化到均值1。AdamW学习率1e-3，权重衰减1e-3，批量64，最多35轮；余弦退火最低学习率1e-4，梯度范数上限5。验证指标改善不足1e-5累计7轮即早停。种子为17、29、43。

训练集预构造6个固定增强视图，每条训练样本每次以0.25概率选择完整输入，其余均分给6个视图。增强视图在T、A、V、TA、TV、AV、TAV七种模态组合、0.1/0.3/0.5/0.7缺失比例、开头/中间/末尾/随机位置之间抽取，种子为7001至7006。正比例缺失按有效槽位数四舍五入（half-up），短样本至少删一个槽位；同步与独立起点按配置选择。

选型指标为`J=0.5*(完整输入MAE+1−Macro-F1)+0.1*sum(五种缺失验证条件的MAE+1−Macro-F1)`，越小越好。五种条件分别为T/A/V/TAV随机缺失30%，以及TAV随机缺失50%，统一验证遮挡种子20260924。结构与早停均由验证集确定，附件3不参与训练或选型。

`模型/final_17.pt`、`final_29.pt`、`final_43.pt`分别对应主实验的`gated_aug_17.pt`、`gated_aug_29.pt`、`gated_aug_43.pt`；导出后参数张量逐项一致，文件序列化哈希以`配置/inference.json`为准。主实验选型记录保留训练检查点的原文件哈希。

最终推理对三模型概率和强度分别平均。全部模态不可观测时，概率回退为`[967,758,1670]/3395`，强度回退为训练集均值`0.16583210777639465`。`代码/inference_ops.py`用显式窗口及线性运算实现同一组卷积参数的推理，训练卷积不改变。

## 5. 复算最终模型的验证与缺失实验

无需重训即可使用提交的三个模型在附件2上评价：

```bash
python 代码/evaluate_final.py \
  --data-root /path/to/赛题数据 --encoder /path/to/distilbert \
  --split valid --scope clean --output 复现输出/验证集完整输入.csv
python 代码/evaluate_final.py \
  --data-root /path/to/赛题数据 --encoder /path/to/distilbert \
  --split valid --scope six --output 复现输出/验证集六场景.csv
python 代码/evaluate_final.py \
  --data-root /path/to/赛题数据 --encoder /path/to/distilbert \
  --split test --scope stress --output 复现输出/测试集缺失实验.csv
```

`clean`只计算完整输入；`six`用于验证集六场景；`stress`计算217次输入实现：完整输入1次，112种主缺失条件对应168次实现，多短段24次，独立起点24次。112种条件为7种模态组合×4种缺失率×4种位置；固定位置1次，随机位置3次。随机重复先在条件内平均，再对所讨论条件等权汇总，不能让随机位置因重复更多而获得更高条件权重。

此入口使用最终统一接口和种子41000+repeat，对应`实验记录/扩展比较/统一接口_验证集指标.csv`、`统一接口_测试集指标.csv`的集成行。六场景另用20260924。完整验证集为728条，主模型Accuracy、Macro-F1、MAE、Pearson按四位小数分别为0.6346、0.6055、0.5784、0.6827。

论文第4.4节主实验使用初始推理规则及测试遮挡种子31000+repeat，结果保存在`实验记录/主实验/`；第4.5节及最终接口增加训练先验回退。权重不变，但4条仅有一个有效词槽的验证样本在遮挡后可能全缺失，使六场景J由0.9919变为0.9926。两套实验的场景随机种子与边界规则须分别匹配，不能混用各表数值。

提交的逐样本记录还可直接重绘验证集混淆矩阵、强度散点图，以及不同模态缺失比例下的曲线，并复算主缺失条件等权均值：

```bash
python 代码/summarize.py --output 复现输出/统计与配图
```

脚本分别导出各张PDF，可在LaTeX中独立排版。若汇总新一轮主实验，增加`--records /path/to/new_problem2_run/results`。

## 6. 从头训练及主消融复现

在新的工作目录重建缓存和训练结果，输出不覆盖提交权重：

```bash
export P2_DATA_ROOT=/path/to/赛题数据
export P2_ENCODER=/path/to/distilbert
export P2_WORKDIR=/path/to/new_problem2_run
export CUDA_VISIBLE_DEVICES=0
export OMP_NUM_THREADS=4
export OPENBLAS_NUM_THREADS=1
python 代码/prepare.py
python 代码/train.py
python 代码/evaluate.py
```

`prepare.py`核对官方划分、词表、标签表与数据接口，拟合训练集标准化参数，生成7个训练视图、6个验证视图及`protocol.json`。`train.py`训练4个单种子基线（text_only/audio_only/vision_only/pooled_clean）及4个三种子主配置（fixed_clean/fixed_aug/mask_aug/gated_aug），总计16次拟合；全部完成后按验证指标生成`selection_lock.json`。`evaluate.py`核验选型锁后评估测试集及主消融，并生成验证集错误分析所需的逐样本预测。训练和主消融沿用原实验计算代码；提交版仅将路径改为可配置目录。

如仅复现最终结构的三次训练，可运行`python 代码/train.py --variants gated_aug`；这一命令不会生成四结构比较的选择锁，不能接着运行要求全部消融模型的`evaluate.py`。完整选型与主消融应使用上面的默认16次拟合流程。完成标记用于跳过已完成拟合，不表示能够恢复中断时的优化器状态；新一次独立实验应使用新的`P2_WORKDIR`。

参考训练启用确定性算法、禁用cuDNN benchmark、线程数4、`CUBLAS_WORKSPACE_CONFIG=:4096:8`。不同硬件与依赖组合可能产生数值差异；提交权重用于固定模型结果核验，从头训练用于复现训练方案及实验流程。

## 7. 实验记录对应关系

- `validation_metrics.csv`：主配置与基线在6个验证条件下的逐种子及集成指标；`seed=ensemble`表示先平均预测，再计算指标。
- `test_metrics.csv`：主实验217次输入实现的模型指标，字段`subset/rate/position/pattern/sync/repeat`分别标识缺失模态、名义比例、位置、连续形状、同步方式和重复序号；实际删除比例见`corruption_audit.csv`。
- `validation_prediction_review.csv`：验证集完整输入与TAV随机缺失50%的逐样本真值、预测、误差和原转写，用于论文验证可视化及错误归因；`validation_error_groups.csv`与`validation_case_studies.csv`提供分组与案例。
- `test_prediction_review.csv`和`error_groups.csv`：测试集对应条件的逐样本与分组误差；不可当作验证集结果。
- `paired_cluster_bootstrap.json`：按源视频聚类配对抽样的指标差异记录。
- `扩展比较/`：论文第4.5节方案比较的数值记录。扩展方案未取代主模型，其预测不用于附件3正式结果。这里只保留比较记录，最终模型的训练、评估与推理代码位于`代码/`。
- `附件3_预测明细.csv`：概率字段为`prob_negative/prob_neutral/prob_positive`；`intensity_seed_std`采用三个种子的样本标准差（ddof=1）；`observed_T/A/V`为有效槽位内的模态观测比例；`all_modalities_missing`标识全部模态不可观测。

所有论文结论以正文为准，上述记录用于追溯数值、复核样本和复现实验，不替代正文的方法与结果分析。
