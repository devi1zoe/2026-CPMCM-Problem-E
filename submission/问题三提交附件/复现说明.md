# 问题三运行与复现说明

## 1. 环境与目录

参考环境为Linux、Python 3.10.13、PyTorch 2.5.1+cu121、CUDA 12.1、NVIDIA GeForce RTX 4090 D。其他版本列于`step3/environment.json`与`step3/requirements.txt`。完整解释程序使用CUDA；冻结文本编码采用FP16，预测模型与梯度计算采用FP32。每个进程线程数4。

```bash
python -m pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu121
python -m pip install -r step3/requirements.txt
```

在本附件根目录运行以下命令。设赛题数据根目录包含“附件2-数据集特征文件”和“附件4-可解释专项视频样本与特征文件”。原始解压目录中，附件4有一层同名目录嵌套；实际路径不同可直接用`P3_SPECIAL`指定包含20个pkl和`videos`的对齐版本目录。

```bash
export P3_DATA_ROOT=/path/to/赛题数据
export P3_SPECIAL=/path/to/附件4/对齐版本
export P3_ASSETS=/path/to/assets
export CUDA_VISIBLE_DEVICES=0
export OMP_NUM_THREADS=4
export OPENBLAS_NUM_THREADS=1
```

`P3_ASSETS`内应有`distilbert/`与`wav2vec2/`两个目录。可复用问题一的冻结资源；也可按锁定版本获取：

```bash
python step3/prepare_assets.py --output /path/to/assets
```

DistilBERT修订版本为`12040accade4e8a0f71eabdb258fecc2e7e948be`；Wav2Vec2修订版本为`22aad52d435eb6dbaf354bdad9b0da84ce7d6156`。前者用于预测文本编码，后者只用于原文时间定位。程序按`assets_manifest.json`核对下载文件，不训练或微调这两个模型。仅重新计算预测和解释、复用已有时间映射时只需DistilBERT，可添加`--models distilbert`。

## 2. 检查已提交结果

无需原始数据或GPU即可执行文件与字段检查；数值复算选项额外需要NumPy：

```bash
python 核验附件.py
python 核验附件.py --numerical
```

检查范围包括20条唯一编号、60条证据、CSV/JSON一致性、字符范围、空时间规则、模态Shapley完备性、728条IG残差和2184行局部删除对照指标。原始关键帧及全部解释可直接在`解释结果查看.html`中查阅。

## 3. 用最终模型重新计算附件4

先新建输出目录，避免覆盖提交结果：

```bash
python 初始化复现.py --output /path/to/p3_replay
export P3_WORKDIR=/path/to/p3_replay
python step3/infer_special.py
python 核验附件.py --numerical --recomputed /path/to/p3_replay/results
```

初始化程序复制选型锁、三个最终权重、标准化参数、训练中位数参考与已有时间映射。`infer_special.py`重新读取20条对齐特征，计算三种子集成、八种模态组合、两种参考贡献、IG与全部等长窗口的原输入删除效应，并重新从原视频提取对应帧。输出位于`P3_WORKDIR/results/`。它不读取附件4标签，也不重新选择预测模型。

若需从原始视频重新计算时间映射，在推理前运行：

```bash
python step3/map_media.py
python step3/infer_special.py
```

此步骤需要Wav2Vec2。音频按16kHz单声道解码，并保留起点偏移；视频使用实际PTS。原转写、词元字符偏移及CTC候选时间共同形成槽位到媒体的对应，时间质量规则沿用`protocol.json`。低置信候选与浏览帧仍按原规则标记，不补造可靠时间。

全部输出保留计算精度，论文展示时才四舍五入。跨硬件或版本可能出现数值差异；专项对照要求类别、主要模态、最终证据窗口与时间状态一致，并以1e-4绝对容差检查强度、贡献及删除效应。

## 4. 验证集解释实验

无需重新训练即可重建完整输入缓存，并用最终权重计算728条验证样本的解释评价：

```bash
python step3/prepare_cache.py --splits train valid
python step3/verify.py
python step3/validate_explanations.py
```

需要附件2的`aligned_50.pkl`。训练集在此仅用于性质检查与已固定处理接口，不更新模型参数。数值缓存写入独立复现目录；不读取问题一生成特征作为本问模型输入。验证输出包括728条预测、三模态Shapley、2184条局部指标、39312次干预及96条稳定性记录。

预测性能用Accuracy、Macro-F1、MAE、Pearson评价。解释局部预算为有效词元槽位的20%，与5个等长随机窗口比较。保留固定的完整输入原预测类别作为所有干预的解释目标，不在删除后切换目标类别。IG积分精度加密依据完备性残差；三种子分歧、小噪声稳定性与基线敏感性分别记录。

完成训练与选型、验证和专项推理的全流程后，可执行`python step3/report.py`从记录生成统计图及数值报告；该程序需要全套验证记录、选型表和三个训练历史。仅进行专项复算时直接使用CSV和JSON即可。

## 5. 数据处理与模型

附件2及附件4均采用对齐输入：`text_bert`为50槽的token ID、attention mask和segment ID，语音为50×74，视觉为50×35；文本由冻结DistilBERT编码为50×768。排除CLS、SEP与填充，文本UNK不视为可恢复语义，视听非零行作为可观测记录。逐维均值与标准差只取训练集可观测位置，标准差下限1e-4，标准化后截断到[-8,8]，缺失行置零。附件4原文件的NumPy2模块名通过兼容读取器映射到NumPy1对应模块，不改动pkl内容。

预测网络为三个64维时序分支，两层核长3、膨胀率1/2的残差卷积，结合观测掩码池化及可用比例、最长缺失比例、序长质量量进行门控融合；输出三分类与3×tanh连续强度。采用三个种子平均类别概率与强度。

问题三的解释需要模型对空模态组合的真实输出，沿用本问模型前向计算；不能将问题二最终统一接口的训练先验回退直接套入问题三，否则会改变空集基线及Shapley值。本附件的`engine.py`与`explain.py`保留论文问题三的计算规则。

## 6. 从初始化模型复现训练与五组候选选择

`训练初始化/step2/checkpoints/`提供四种主配置的三个种子参数，共12个检查点：门控增强模型用于微调初始化，另外三组用于论文表5.2的候选比较。只给最终三个权重不足以直接重做五组选择，因此保留这些必要初始化参数；不包含问题二未采用的扩展模型。

另建训练目录：

```bash
python 初始化复现.py --output /path/to/p3_training --training
export P3_WORKDIR=/path/to/p3_training
python step3/prepare.py
python step3/train.py
python step3/verify.py
python step3/validate_explanations.py
python step3/map_media.py
python step3/infer_special.py
python step3/report.py
```

训练只用附件2训练划分3395条，验证划分728条用于早停和选型。AdamW学习率3e-4、权重衰减1e-3，批量64，最多20轮；余弦退火最低学习率3e-5，梯度范数上限5，Dropout 0.2，早停耐心5、最小改善1e-5。损失为训练频率加权交叉熵与SmoothL1之和。每条样本80%概率保持三模态完整，20%概率在7个真子集合中均匀抽取，包含空集。第0轮原参数也参加验证检查点选择。

种子17、29、43分别训练，按完整验证集`MAE+1−Macro-F1`比较五种候选的三种子集成，锁定最低者。本次为组合增强模型，最佳轮次1、2、0；不能将第0轮保留描述为已更新参数。附件4不参与选型。

训练中位数参考只从训练集标准化后的可观测表示计算，供解释参考敏感性比较使用。`prepare.py`按需要重建训练/验证缓存，不依赖随包提供大缓存。训练完成标记仅用于跳过已完成拟合，不能恢复中断的优化器状态；独立实验应使用新的输出目录。

如果需要连同问题二初始化模型一起从头训练，先按问题二附件的主实验流程生成全部主配置检查点，再设置`P3_P2_ROOT=/path/to/problem2_run`，执行上述问题三流程。重新训练不保证在不同软硬件下逐位一致；固定提交模型的数值核验与训练流程复现分别进行。

## 7. 路径及交付边界

`P3_WORKDIR`控制缓存、检查点与结果输出；`P3_DATA_ROOT`控制官方数据根目录；`P3_SPECIAL`可直接指定附件4对齐目录；`P3_ASSETS`控制公开冻结模型目录；`P3_P2_ROOT`可覆盖默认的训练初始化目录。程序路径无需与原实验机器相同。

`step3/selection_lock.json`记录原实验模型和配置哈希，最终三个文件在本附件中保持原字节。`protocol.json`、`analysis_protocol.json`和`numerical_protocol.json`分别约束训练、解释比较及数值积分规则。源视频引用相对于赛题数据根目录；`cards`图像引用相对于对应`results`目录。

原始数据、原视频、公开大模型、Python安装目录和可重建缓存不重复提交。完整预测、贡献、证据、时间限制与必要验证记录随附件保留，论文方法和结论仍以正文为准。
