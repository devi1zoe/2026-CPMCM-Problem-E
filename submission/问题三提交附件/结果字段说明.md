# 问题三结果字段与解释口径

## 正式CSV

文件为`step3/results/附件4_问题三预测与解释.csv`，编码UTF-8（带BOM），共20条记录。

| 字段 | 定义 |
|---|---|
| `sample_id` | 原始pkl与视频文件的两位编号字符串 |
| `polarity` | `negative`负向、`neutral`中性、`positive`正向 |
| `intensity` | 三个模型强度的平均值，范围[-3,3] |
| `main_modality` | 主要参考模态；本批为`text`或`vision` |
| `contribution_text` | 文本对完整输入原预测类别概率的有符号Shapley贡献 |
| `contribution_audio` | 语音对同一目标的有符号Shapley贡献 |
| `contribution_vision` | 视觉对同一目标的有符号Shapley贡献 |
| `evidence` | 合法JSON数组，按text、audio、vision排列的三条局部证据 |

分类头的平均概率最大项确定极性，回归强度单独输出；不按回归值的正负覆盖分类，也不将中性强度置零。

```python
import json
import pandas as pd
rows = pd.read_csv('step3/results/附件4_问题三预测与解释.csv',
                   dtype={'sample_id': str})
evidence = json.loads(rows.loc[0, 'evidence'])
```

## 模态贡献

对三种模态枚举全部8种保留组合。主基线将被移除模态的特征置零、观测掩码置为不可用并重算质量量；分类解释始终固定为完整输入原预测类别，强度贡献另行计算。类别贡献总和等于完整输入与空模态输入的固定目标概率之差。负贡献表示对原预测类别的抑制，不能作为支持程度使用；不同样本的解释目标可能不同，不直接比较其贡献为共同的情感强度。

`special_modality_contributions.csv`每个样本包含三行。`class_shapley`为类别贡献，`intensity_shapley`为强度贡献，`absolute_share`为绝对类别贡献占绝对贡献总和的比例。主要模态取绝对贡献最大项；总绝对贡献小于0.001时记为`weak`，最大占比不足0.45时记为`mixed`。本批均满足主导条件，分别为文本17条、视觉3条。

`reference_class_shapley`等字段采用训练集可观测标准化特征的逐维中位数替换，并保持原观测掩码；这是不同的参考定义，用于敏感性分析。`*_seed_std`为三个种子之间的样本标准差，`main_seed_agreement`为主要模态的一致比例，均不表示真实误差或置信区间。模态贡献也不等同于融合门控权重。

## 局部证据

| evidence内字段 | 定义 |
|---|---|
| `modality` | text、audio或vision |
| `slot_start/slot_end` | 模型槽位半开区间，索引从0开始 |
| `char_start/char_end`、`text` | 原转写字符半开区间及其原文片段 |
| `fixed_target_class` | 固定原预测类别编号：0负向、1中性、2正向 |
| `class_probability_drop` | 完整输入目标概率减去删除窗口后的目标概率 |
| `intensity_delta` | 完整输入强度减去删除窗口后的强度 |
| `role` | 删除效应大于0.001为supporting，小于−0.001为inhibitory，其余为weak |
| `ig_candidate` | 表示层IG筛选的窗口、归因和与原输入删除确认结果 |
| `time_status` | estimated_CTC或unverified_candidate等定位状态 |
| `start_seconds/end_seconds` | 通过检查的估计起止秒数；未通过时为null |
| `candidate_start_seconds/candidate_end_seconds` | 保留供核查的候选时间，不能代替正式可用时间 |
| `keyframe` | 视觉证据关联帧的索引、实际PTS、图片路径和类型 |

窗口长度取有效词元槽位数的20%，half-up取整，至少1槽。IG用于筛选连续表示中的候选，原文本删除必须在冻结编码之前修改token及attention。专项结果探测全部等长窗口：优先选取最大正删除效应，若不超过0.001则保留绝对效应最大窗口，并注明方向。专项穷举后的最大效应不作为独立忠实性证明；验证集上预先按IG选择窗口，再与5个等长随机窗口比较。

音频和视觉证据旁的原文片段是其对齐槽位的定位参照，不表示音频或视觉特征由该文本替代。IG保持有效位置、观测掩码和质量量固定，仅用于连续表示归因。

## 时间与视频对应

原文字符通过分词偏移映射到模型槽位，再由给定原文的CTC强制对齐估计词时间。诊断识别不替换原文，不按`槽位/50×视频时长`生成时间。定位不是官方特征时间戳，只有通过片段级和局部词置信度检查的窗口才填入正式秒数。

15、16号触发整段复核；其他样本也可能只有某些局部窗口不可用。`mapping/`保留诊断WER、词置信度及原因，未确认区间的正式时间为null。`context_preview_not_localized_evidence`表示全片浏览帧；`estimated_local_evidence_frame`表示按估计视觉区间提取的帧，另以`inside_estimated_interval`指示是否落在区间内。图片路径相对于`step3/results/`；源视频路径相对于赛题数据根目录。

## 验证记录

`validation_prediction_metrics.csv`对应论文表5.2的五种候选集成及逐种子指标。`validation_predictions.csv`包含逐样本真值和预测；`error_groups.csv`与`representative_errors.csv`支持误差分组及案例分析。

`validation_fidelity.csv`包含728×3=2184行局部验证记录；`validation_probe_outputs.npz`保存39312次删除/保留操作及输出。条件保留仅保留指定模态内的窗口而使其他模态完整；无条件保留只留下这一个模态的该窗口。`validation_fidelity_comparison.csv`保留与等长随机窗口的对照；主要模态统计、三模态统计与正确/错误预测分组应分别解读。

`validation_coalitions.npz`保留三种子、八种组合的输出及固定目标；`validation_ig.npz`保留积分归因、窗口和残差。积分节点由32开始，按完备性残差依次加密为64、128、256，容差0.001；只用数值恒等式检查精度，不用标签或删除结果调整节点。`validation_stability.csv`记录96条样本的种子和小扰动稳定性，扰动为标准化表示上的0.02标准差高斯噪声。预测性能、解释忠实性、时间定位及稳定性是不同检查对象。
